# PocketDev — Risk Register

| # | Risk | Impact | Likelihood | Mitigation | Status |
| --- | --- | --- | --- | --- | --- |
| R1 | No reliable ARM64 Android environment in GitHub Actions | Bionic runtime never validated end-to-end | High | **Measured (Milestone 2, `docs/ARM64_FEASIBILITY.md`):** x86_64 runners reject ARM64 guests (emulator 37.3.10 arch check); `ubuntu-24.04-arm` has no emulator package and no `/dev/kvm`. ARM64 builds are cross-compiled on `x86_64` (native `ubuntu-24.04-arm` builds fail at `aapt2`, x86_64-only); runtime tests run on `x86_64` API 30; ABI-agnostic design + static ELF checks; ARM64 device proof deferred | Open — accepted gap |
| R2 | Device storage nearly full (~4.5 GB free) | Cannot hold large artifacts locally | Medium | Never build locally; keep only source on device; clean project downloads | Mitigated by policy |
| R3 | FUSE storage quirks (`safe.directory`, symlink semantics) | Git/runtime extraction oddities | Medium | `safe.directory` configured; test extraction on app-private ext4 storage | Partially mitigated |
| R4 | Termux GPLv3 + file-level exceptions complicate licensing | Distribution/legal exposure | Medium | File-level license inventory before redistribution; keep components modular | Open |
| R5 | OpenCode Bionic artifact size / APK size | Installability, update bandwidth | Medium | Measure in CI; hybrid provisioning evaluation (prompt §9.3) | Open |
| R6 | Android background process limits kill runtime/agent | Broken sessions | High | Foreground service only when justified; graceful recovery | Open |
| R7 | AGP/Kotlin/Gradle version drift breaks CI | Build failures | Low | Pinned versions + wrapper checksum; Renovate-style manual review | Mitigated |
| R8 | Emulator tests slow/flaky in CI | Noisy gate, wasted minutes | Medium | Small high-signal matrix; SHA-scoped concurrency with no cancellation of earlier commits; diagnostics on failure; deterministic latches for transient state; Compose navigation flake on `a89442a` API 36 was rerun clean without weakening tests | Open |
| R9 | Agent misuses filesystem/commands | Data loss | Medium | Path safety in `:core`; permission model (prompt §10.2); confirmations | Partially mitigated |
| R10 | Secret leakage into logs | Credential compromise | Medium | `SecretRedaction`; Android Keystore AES/GCM with randomized IV (no plaintext preferences); `RuntimeAgentConfig` emits only the `{env:POCKETDEV_API_KEY}` placeholder and redacts values from `RuntimeLaunchPlan`; real key only enters child-process env; no secrets in source | Partially mitigated |
| R11 | Android 10+ W^X: targetSdk 36 app cannot `execve()` files in app data | Bootstrap binaries unrunnable | High | `linker64` first-hop proven on the API 30 emulator (ADR-0002, run `44876316131`: relocated `bash`/`ls` run, direct exec blocked as expected); shebang/`exec` works with stock `termux-exec` when `TERMUX_APP__DATA_DIR`/`TERMUX__PREFIX` env are set (run `44878997591`) | Mitigated — linker hop + shebang exec both proven |
| R12 | Stock Termux packages hardcode `/data/data/com.termux` prefix | Runtime breaks under `dev.pocketdev` data dir | High | **Decided in ADR-0002:** keep our prefix, relocate symlinks, launch via `linker64`, ship the stock `termux-exec` preload from the pinned bootstrap; `TERMUX_APP__DATA_DIR` and `TERMUX__PREFIX` env override make shebang exec work (run `44878997591`) | Mitigated — binary launch + shebang exec both proven |
| R13 | No entitled package repository for a non-`com.termux` app id | `apt install` unavailable or upstream-hostile | Medium | ADR-0002 selected a relocated stock bootstrap; no repository is configured and upstream intent is respected (audit §C4) | Open |
| R14 | `opencode serve` readiness is a printed text contract, not a versioned API | Server capture silently hangs if upstream wording changes | Low | Isolated in `OpenCodeServeOutputParser`; pinned release (`v2.3.2`) audited in ADR-0004; loopback-only, fail-closed on non-loopback URL; parser unit tests fail loudly on change; server reports real `Failed`/`Exited` | Mitigated — isolated + tested |
| R15 | OpenCode server password/auth exposure | Unauthorized local access to agent | Medium | Bind `127.0.0.1` explicitly (ADR-0004); HTTP Basic with per-run random password captured in memory only; never logged or persisted; loopback host validated before accepting connection | Mitigated by design |
| R16 | PTY child-status and cross-thread lifecycle races | HUNG sessions, missed exits, fd/thread leaks, deadlocks | High | Pre-fork argv/env/error-pipe setup; checked child setup calls; waitpid status cache; poll-based reader with close flag; separate listener/lifecycle/operation locks; idempotent close; JVM and opt-in instrumentation stress coverage | Mitigated — PR #39 CI and runtime spike `45336872176` verified |
| R17 | Blocking filesystem/SAF work stalls the UI thread | ANRs during recursive copy/delete/search/import/export | Medium | Suspend `WorkspaceFiles` operations with `ensureActive()`, `Dispatchers.IO` for filesystem/SAF work, Main-only state updates, progress/cancel UI, explicit partial failure, and JVM/instrumentation coverage on `de36fe8` | Mitigated — PR #39 API 29/36 green |
| R18 | OpenCode env-auth/provider handshake assumptions do not match the pinned binary | Sessions start without the selected model or provider key | Medium | Inline `OPENCODE_CONFIG_CONTENT` JSON, `{env:POCKETDEV_API_KEY}` placeholder, session create/switch-model wire tests, redaction tests, and AppContainer/controller/workspace wiring; real device provider response remains unverified under R1 | Partially mitigated |
| R19 | Editor loads only the first 1 MiB and rejects binary/symlink files | Large, binary, or symlink files cannot be edited | Medium | Hard `WorkspaceFiles.DEFAULT_MAX_TEXT_BYTES` cap, `truncated` read-only state with UI warning, binary/NUL rejection, symlink refusal, and stale-signature save guard; no partial file is silently overwritten | Mitigated by explicit limitation |
| R20 | Save race or stale-write overwrites newer editor/user content | Data loss | High | Tabs keyed by `EditorDocumentId(workspaceId, rootPath, relativePath)`; `EditorBuffer.markSaved(savedRevision, savedText)` clears dirty only on exact match; saves require the observed `FileSignature`; concurrent writes serialized; regressions on late saves, project switch, same-size external replacement, and commit failure | Mitigated — M7.5 CI green |
| R21 | External file modification while a tab is open | Silent overwrite or lost edits | High | Content digest is the primary change signal; dirty changes become explicit conflicts until resolved; clean tabs reload automatically; same-size/timestamp-restored replacements are detected; no silent overwrite path remains | Mitigated — M7.5 CI green |
| R22 | Unsaved draft recovery loses work or restores stale content | Data loss or resurrected old text | High | App-private versioned drafts under `RuntimePaths.drafts`; schema/version and oversize rejection; `EditorDraftRead.Missing/Usable/Unreadable`; unreadable/unknown-version raw bytes retained; auto-restore only on disk hash+size equality; conflicts require explicit `restoreDraft()`/`keepDiskDraft()`; successful actions delete draft | Mitigated — M7.5 CI green |
| R23 | Provider-specific staging/atomic-move semantics differ from local ext4 | Partial files or temp residue on some storage providers | Medium | Stage then `Files.move(..., REPLACE_EXISTING, ATOMIC_MOVE)` with fallback; temp cleanup on staging/commit failure; stale-signature guard; unit regressions for staging and commit failures. SAF/provider-specific behavior is not proven on every device | Partially mitigated |
| R24 | IME composition, Unicode, or selection offset corruption | Broken input, crash, or invalid surrogate ranges | Medium | Compose tests cover composition surviving syntax updates, Unicode/Persian input, selection bounds, and supplementary-plane replacement; core buffer/search tests cover supplementary Unicode; x86_64 emulator evidence only | Mitigated on x86_64; ARM64 device gap remains |
| R25 | Editor performance regresses near the 1 MiB limit | Jank or slow save/open | Medium | Committed JVM and Android x86_64 baselines with deterministic fixtures, warm-ups, sample counts, percentiles, and correctness assertions; no thresholds or optimizations applied in Phase 10 | Open — monitored baseline |
| R26 | Symlink components escape the selected project root during editor IO | Unauthorized file read/write | Medium | `PathSafety.resolveWithinNoFollow` rejects existing symlink files and directory components; `WorkspaceFilesEditorTest` and `PathSafetyTest` cover rejection; editor paths remain rooted in canonical `Project.rootPath` | Mitigated — M7.5 CI green |
